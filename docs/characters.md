## Selection

- Each monster can only be picked once per match. Monsters that are already taken are greyed out.
- Players pick in reverse turn order, so the player who moves last picks first.
- Each player has 30 seconds to pick. If time runs out, a random monster is picked.

## Abilities

Each monster will get its own special ability, but **none in the first playable** (Q15). The user turned down discussing abilities in Q05 and Q07 because they wanted the main rules settled first. Bring abilities up again after the first playable is built, not before.
