# Questionnaire 09: Before the First Night

## 1. What should the very first playable version include?

A small version where I control everyone, and there's no minigames.

## 2. Should the game be in Turkish, English, or both?

English for now, but prepare it so that it's easy to sub in other languages.

## 3. What happens if someone disconnects mid-match?

There's an expiry period for every decision. If it's not made by then, a random choice is made.

## 4. Which fun stats should the end screen show?

Eh, don't care.

## 5. How should the quick spaces be split?

All about equal, regardless of setting.
