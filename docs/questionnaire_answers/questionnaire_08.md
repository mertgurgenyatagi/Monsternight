# Questionnaire 08: Polishing the Rules

## 1. What does the challenger risk?

If you lose a swap duel nothing happens. For the other ones, you lose that thing.

## 2. How does the finish line work?

Any roll that reaches it counts. No checkpoints.

## 3. Did I get the trophy details right?

Yes to all.

## 4. How common should minigame spaces be?

Three-to-two roughly. For every three spikes/thief/church/coin, there are two minigames.

## 5. What happens when the match ends?

Trophy ceremony, definitely. Fun stats, yeah. Back to lobby, yeah.
